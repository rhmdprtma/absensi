# Check-in Berdua ❤️

Web check-in simpel buat lu & doi, biar saling tau lagi ngapain, dimana, sama siapa.
Semua check-in langsung kesimpen otomatis di Google Sheet.

**Live Demo:** https://tamayana.github.io/absensi/

---

### ✨ Fitur

- 📍 Check-in lokasi, makan, kangen, sebelum tidur, dll
- 📝 Catat lagi ngapain, sama siapa, dan dimana
- 📸 Upload foto langsung dari HP
- 📖 Riwayat check-in berdua, bisa dilihat kapan aja
- 📊 Data tersimpan otomatis di Google Sheet
- 📱 Mobile-friendly, tanpa login, tanpa install

### 🛠️ Dibuat Dengan

- HTML, CSS, JavaScript
- Google Apps Script (Backend)
- Google Sheets (Database)
- GitHub Pages (Hosting)

### 🚀 Cara Pakai

1. Buka https://tamayana.github.io/absensi/
2. Pilih nama lu
3. Pilih jenis check-in
4. Isi lagi ngapain, sama siapa, lokasi
5. Upload foto kalo ada
6. Pencet **Kirim Check-in 💌**
7. Selesai! Data langsung masuk ke Sheet & muncul di Riwayat.

### 📊 Struktur Data di Sheet

| Nama | Jenis | Waktu | Ngapain | Sama Siapa | Lokasi | Foto |
| --- | --- | --- | --- | --- | --- | --- |
| Rahmad | 📍 Lagi di mana | 20/11/2026 15:15 | Lagi di jalan pulang | Sendirian | Bekasi | ... |

### 🔧 Cara Deploy Ulang

1. Edit `index.html` di repo ini
2. Ganti `SHEET_URL` di dalam file dengan URL Web App dari Google Apps Script lu
3. Commit, GitHub Pages akan update otomatis dalam 1 menit
